# Pikachu Tile Character Pack

Folders:
- `png_512/`: source-quality transparent PNGs.
- `png_256/`: optimized runtime PNGs.
- `atlas/tiles_256.png + .json`: recommended PixiJS runtime atlas.
- `atlas/tiles_512.png + .json`: high-resolution atlas.
- `preview/contact_sheet.png`: final visual review.
- `manifest.json`: asset names and atlas frame IDs.
- `AUDIT.md` / `audit.json`: final validation results.

Recommended runtime atlas: `atlas/tiles_256.json`.
